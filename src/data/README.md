# Dados locais

Dados de exemplo ou valores iniciais usados pela interface quando apropriado.

## Arquivos importantes
- `points.ts`: conjunto `initialPoints` com pontos de exemplo tipados como `PetPoint`.

## Orientações para agentes
- Trate estes valores como dados locais de demonstração, não como fonte persistente do backend.
- Mantenha os objetos compatíveis com `src/types.ts` e não inclua informações pessoais ou credenciais reais.
